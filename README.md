# agriEquity

Equity and sustainability assessment of agricultural subsidies: who
benefits, how progressive the support is, and what a budget-neutral
reallocation could achieve for productivity, equity and the environment.

| Function | Purpose |
|---|---|
| `benefit_incidence()` | Benefit shares, parity, coverage by group or quantile |
| `progressivity_index()` | Concentration, Kakwani, Reynolds-Smolensky, bootstrap CIs |
| `subsidy_equity()` | Multi-dimensional equity scorecard with Theil decomposition |
| `distributional_effects()` | Gini and FGT poverty with and without support |
| `budget_reallocation()` | Budget-neutral rules incl. welfare-optimal allocation |
| `tradeoff_frontier()` | Productivity-equity-sustainability frontier |

The `farm_subsidy` example data are simulated.
